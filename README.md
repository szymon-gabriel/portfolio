# Creative Developer Portfolio

A premium, production-ready software engineering portfolio designed from scratch to showcase advanced front-end capabilities, custom workflow automation tools, and native browser utility implementations.

---

## 🚀 Live Production Environment

The portfolio is fully deployed and optimized for all viewports, featuring an integrated multi-language state management architecture.

**Explore the live portfolio here:** https://szymon-gabriel.github.io/portfolio

---

## 🧠 Engineered Features & Core Architecture

* **Custom i18n Localization Engine:** Native JavaScript translation architecture in `script.js` allowing seamless toggle operations between English and Polish layouts without external framework dependencies.
* **Flawless Responsiveness (RWD):** Mobile-first refined fluid grid and layout structure, fully optimized against viewport overflow for a clean presentation across all modern mobile and desktop screens.
* **Interactive Micro-Interactions:** Modern UI styling built upon deep contrast mechanics, subtle hover animations, custom element accents, and performance-minded performance layouts.
* **Centralized Project Hub:** Showcases architectural progression from standalone legacy Object-Oriented Programming (OOP) in Java to complex client-side binary data processing systems.

---

## 🏗️ Repository Directory Layout

* `index.html` - Core application layout orchestration layer integrated with dynamic localization keys.
* `style.css` - Custom structural blueprint, animation typography architecture, and theme definitions.
* `script.js` - Main application engine handling core routing, i18n localization dictionary, and UI state tracking.
* `assets/` - Directory housing media, custom icons, and interactive visual components.

---

## ⚙️ Core Technology Stack

* **JavaScript (ES6+):** Pure object routing, i18n dictionary state management, UI element manipulation, and system logic.
* **HTML5 / CSS3:** Advanced semantic structural mapping, custom CSS variables, and native animation layers.
* **Web Browser APIs:** Localized component integration ensuring persistent workflow tracking.
